# Security Policy

## Supported Versions

Security fixes are made on the `main` branch. Only the latest state of `main` is supported; please
make sure an issue is still reproducible there before reporting it.

## Reporting a Vulnerability

Please do **not** report security vulnerabilities through public GitHub issues, pull requests or
discussions.

Instead, report them privately using GitHub's private vulnerability reporting:

1. Go to the [Security tab](https://github.com/walidbadar/zephyr-i2c-tiny-usb-bridge/security) of
   the repository.
2. Click **Report a vulnerability** to open a draft security advisory.
3. Describe the issue, the affected version or commit, and the steps needed to reproduce it.
   A proof of concept, the board used and any relevant logs are very helpful.

This is the only channel for reporting vulnerabilities. Reports will be acknowledged and analyzed
within 1 week. You will be kept informed through the advisory as a fix is prepared, and credited
in the published advisory unless you prefer to remain anonymous.
